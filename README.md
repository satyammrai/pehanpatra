# Satyam Rai — Portfolio Website

Personal portfolio built with **React**, **TypeScript**, **Tailwind CSS v4**, and **Vite**, showcasing ML research projects, full-stack web apps, and client websites.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deploying

- **Netlify / Vercel**: Connect your GitHub repository with build command `npm run build` and publish directory `dist`.
- **GitHub Pages**: Either connect the repository in **Settings → Pages** (by adding a GitHub Actions workflow directly in the GitHub UI) or publish the generated `dist/` folder via `gh-pages`.
